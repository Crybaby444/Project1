# SEO audit — yoyo.rent, 2026-11-16

Tool: claude-seo v2.6.2 (`seo-audit`: render_page, page_checks, transport_check, agentic_check, sitemap_discovery), run inline. PageSpeed Insights was rate-limited without an API key, so there are no lab or field Core Web Vitals in this audit.

Business type: two-sided rental marketplace (peer-to-peer), one city (Riga), three languages.

## What already worked
- Sitemap index (pages, categories ≥3 items, listings), valid; robots.txt names it.
- hreflang in HTML and the `Link` header, x-default, canonical on every page.
- Product + Offer + Person + Place JSON-LD on items; FAQPage on /faq; Organization + WebSite + SearchAction on the home page.
- noindex on thin categories (<3 items), search results, auth and private screens.
- HTTPS with HSTS; www and http redirect.

## Findings and what was done (PR #69)
| Severity | Finding | Fix |
|---|---|---|
| High | Home HTML 789 KB (150 KB gzip): the 130 KB stylesheet was inlined 4× (`experimental.inlineCss`) and every page shipped all ~90 KB of interface texts | inlineCss off; admin, style guide and server-only texts no longer sent site-wide. Home now 150 KB raw / 40 KB gzip |
| Medium | Item titles were the bare name ("PlayStation5 pro · Yoyo") | "{title} for rent in {city, district}" in 3 languages |
| Medium | Category titles short ("Tools for rent") | "{name} for rent in Riga" in 3 languages |
| Medium | Home meta description 166 characters | ≤145 in 3 languages |
| Low | What is Yoyo / How it works / FAQ / legal pages had no og:image (a page's own openGraph dropped the inherited card) | pageMetadata names the language's card |
| Low | No breadcrumb structured data | BreadcrumbList wherever breadcrumbs show |
| Low | No llms.txt | /llms.txt: what Yoyo is, deal rules, pages in 3 languages, categories |
| Low | Security headers missing (nosniff, framing, referrer, permissions; HSTS without subdomains) | Set in next.config `headers()` |
| Low | /bookings, /wallet not in robots.txt (already noindex) | Added |

## Still open
- **Content depth (Medium).** Home 191 words, category pages ~90, items ~150. Ideas: a short intro per root category (what people rent, typical price per day, deposit range), district landing pages once there are enough items, guides ("How much does it cost to rent a drill in Riga").
- **Real Core Web Vitals.** Add a Google API key (`/seo google setup`) for PageSpeed and CrUX, and connect Search Console for indexing and queries.
- **Listings count.** Production has one item; most categories stay noindex until they have three.
- **Off-site.** Google Business Profile is not applicable to an online marketplace, but brand mentions, Latvian directories and social profiles (`sameAs` in Organization) help entity recognition and AI citations.
- **Content-Signal in robots.txt** (search=yes, ai-input=yes; ai-train is the owner's call).

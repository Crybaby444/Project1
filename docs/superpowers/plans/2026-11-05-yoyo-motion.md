# Yoyo — План «Движение»: система анимаций сайта

**Цель:** сайт выглядит живым и радует глаз, но остаётся быстрым, доступным и читаемым. Девять приёмов движения переложены в собственный стиль Yoyo — Sticker: небесная бумага `#dceeff`, контуры 1px, пилюли, наклейки, Unbounded 800/900 и Onest, кривая `cubic-bezier(.2,.8,.2,1)`. Внешний вид, названия, рисунки и раскладку сайтов-примеров не копируем, берём только приёмы.

**Правила (DESIGN.md, «Project adaptations» §1, редакция от 2026-11-05):**
- анимируются только `transform` и `opacity`: без сдвига раскладки (CLS 0), работу делает компоновщик, 60 fps;
- эффекты, привязанные к прокрутке, сделаны на CSS scroll-driven animations (`animation-timeline: view()`). Где их нет (Firefox, Safari до 26), работает запасной путь на IntersectionObserver или кадровом цикле, и только пока элемент на экране;
- всё, что повторяется (покачивание, бегущая строка), идёт только на экране;
- при `prefers-reduced-motion` всё неподвижно и полностью читается;
- на тач-экранах параллакс слабее (48px вместо 120px), наклона карточек нет;
- 320 и 390 px, обе темы, EN/LV/RU: длинные слова не вылезают за край;
- без тяжёлых зависимостей: ни одной новой библиотеки. Переходы между страницами — View Transitions через `TransitionLink` и `switch-page.ts` из плана 12.

## Примитивы — `apps/web/src/components/motion/`

| Примитив | Приём | Как устроен | При уменьшенном движении |
|---|---|---|---|
| `useInView`, `useReducedMotion`, `useScrollFallback`, `useHydrated` (`hooks.ts`) | ленивый старт | IntersectionObserver; без него элемент считается видимым | — |
| `ToneSection` | 1. смена цвета фона по разделам | у каждого раздела фиксированный слой своего тона; `opacity` идёт по view-timeline раздела, запасной путь — IO по середине экрана | раздел — плоская цветная полоса |
| `WordFill` | 2. текст проявляется по словам | слова в `span`, у каждого свой отрезок `animation-range`; запасной путь — `--wf-p` из кадрового цикла. Бледное состояние — половина непрозрачности: на всех тонах в обеих темах это всё ещё AA для крупного текста, поэтому только для крупных жирных фраз | весь текст чёрный |
| `StickyStack` | 3. карточки «как это работает» ложатся стопкой | `position: sticky` с растущим `top`, наклон ±1° | обычный список; на экранах ниже 560px тоже |
| `ParallaxScope`, `Parallax`, `driftStyle`, `Bob` | 4. плывущие наклейки, 7. покачивание | область измеряется и не двигается, слои внутри сдвигаются свойством `translate` (оно складывается с `rotate` и `transform` наклейки); `Bob` — CSS-цикл только на экране | неподвижно |
| `Marquee`, `MarqueeRow` | 5. бегущие ряды слов-пилюль | ряды в противоположные стороны, копия `inert` и `aria-hidden`, пауза при наведении и фокусе, одна кнопка паузы на все ряды (WCAG 2.2.2) | ряды переносятся в неподвижный блок, копия скрыта |
| `Tilt` | 6. бенто-карточки | наклон к мыши до 4°, лицо поднимается над чернильным слоем (жёсткая тень `0 4px 0`), `[data-bounce]` подпрыгивает | без наклона и подъёма |
| `LetterRise`, `Wordmark animated` | 7. буквы заголовка поднимаются | слово поднимается (inline-block), буквы внутри — обычный текст и проявляются по очереди. Текст в DOM ровно один раз, без `aria-label` и скрытых копий: читалка слышит слова, а не «N e w», и поле с тем же названием остаётся единственным | буквы на месте |
| `TransitionLink` + `switch-page.ts` (из плана 12) | 8. переходы страниц | одна View Transition на переход: затухание с лёгким масштабом (`html[data-page-switch]`), шапка стоит на месте; так же устроено переключение языка | мгновенно |
| `CountUp` | 9. счётчики | невидимое итоговое число держит ширину, бегущее число лежит сверху, читалка слышит итог | сразу итог |
| `Reveal` | вспомогательный: появление при прокрутке | view-timeline; запасной путь — IO + `@media (scripting: enabled)` | сразу видно |

Микровзаимодействия (9): у всех пилюль и кнопок подъём при наведении и `active:scale-[0.96]` (Button, IconButton, Chip, GoogleButton, ThemeSelect, SettingsTabs, UserMenu, ErrorView). Переключатель языка остался прежним, но вместо шторки теперь затухание с лёгким масштабом (`globals.css`, `html[data-language-switch]`).

Тона фона — токены `--tone-*` в `tokens.css`. Это `light-dark()`: в светлой теме цвет наклейки смешан с белым (чёрный текст проходит AA), в тёмной — слабый оттенок тёмного холста (белый текст проходит AA).
